Honest notes — please read

    
    
      
  • CNIC aur NTN validation sirf FORMAT ki hai. Ye kisi asli shakhs ya business ko NADRA ya FBR se verify nahi karta, kyunki wo data public nahi hai. Sahi format ka matlab sirf ye hai ke number likhne ka tareeqa durust hai.
    • 
      
  • IBAN checksum asli mathematical check hai (MOD-97, ISO 13616). Ye ghalat check digit pakar lega, lekin ye bhi account ke maujood hone ki guarantee nahi deta.
    • 
      
  • Ye demo local hai: koi data server par nahi bheja jata, koi API key nahi chahiye.
